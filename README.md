# Canvas Dark Mode

Canvas was bright, so this makes it dark.
Your assignments remain due.

1. [Download the extension ZIP](https://github.com/partypancake8/canvas-drkmode/raw/refs/heads/main/dist/canvas-dark-mode-1.0.0.zip) and unzip it.
2. Open `arc://extensions` in Arc or `chrome://extensions` in Chrome.
3. Enable **Developer mode** and click **Load unpacked**.
4. Select the extracted **canvas-dark-mode** folder, or the **extension/** folder if you cloned this repository.
5. Refresh Canvas and keep the extension folder where it is.

Open the extension popup to turn dark mode on or off for the current site.
If your school uses a custom Canvas address, enter its hostname in the popup and grant access.
This changes how Canvas looks; it does not do your homework.
